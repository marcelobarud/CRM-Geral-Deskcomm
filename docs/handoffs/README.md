# Handoffs históricos

Estes documentos registram o contexto de trabalhos e épicos anteriores. Não são regras globais, estado vivo ou backlog vigente do CRM Geral. Revalide decisões, ambiente, caminhos, código e autorização antes de executar qualquer ação descrita. Expressões “permanente” e “sempre” ficam limitadas ao trabalho original.

Novos handoffs devem nascer nesta pasta, com data, escopo, revisão de referência e status; não crie novos handoffs na raiz. O contrato global é AGENTS.md e a hierarquia está em [AGENT_INSTRUCTION_HIERARCHY.md](../AGENT_INSTRUCTION_HIERARCHY.md). Os 12 documentos movidos da raiz na Fase 2.0.1 conservaram seus corpos; caminhos relativos no corpo mantêm o contexto da raiz original e devem ser revalidados.
